# بسته اعتبارسنجی داده‌های ایستگاه هواشناسی

این پوشه شامل ورودی‌های مرجع کوچک و قابل بازتولید برای آزمون ورود داده و کنترل کیفیت Mahras است. این فایل‌ها داده اندازه‌گیری واقعی یا گواهی کالیبراسیون نیستند؛ داده‌های مصنوعی با مقادیر فیزیکی معقول‌اند تا تبدیل واحد، زمان، کنترل کیفیت و ذخیره‌سازی نرم‌افزار آزموده شود.

## فایل‌ها

- `station_sample_valid.csv`: ۲۴ مشاهده ساعتی با timestamp دارای UTC، سرعت باد m/s، جهت درجه، دما °C، فشار hPa و رطوبت نسبی درصد.
- `station_sample_edge_cases.csv`: نمونه‌های مرزی/نامعتبر برای آزمون ردیف ناقص، مقدار فیزیکی نامعتبر و تندباد کمتر از سرعت میانگین.

## روش اجرا

از ریشه مخزن:

```bash
python -m unittest discover -s tests -p 'test_station_data.py' -v
python -m unittest discover -s tests -p 'test_weather*.py' -v
```

برای ورود نمونه سالم از رابط «آب‌وهوا و AI مهراس» و دکمه «ورود داده ایستگاه و پارامترهای فیزیکی» استفاده کنید. منطقه زمانی فایل نمونه UTC است.

## انتظار

فایل سالم باید ۲۴ ردیف پذیرفته‌شده، بدون رد و بدون پرچم مشکوک داشته باشد. فایل مرزی باید دست‌کم یک ردیف ردشده و یک ردیف مشکوک تولید کند. مقدارهای خام، فایل اصلی، SHA-256 و گزارش هر batch در SQLite نگهداری می‌شوند.
