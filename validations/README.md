## اجرا

از ریشهٔ مخزن:

    python validations/run_validation.py --latitude 37.64287 --longitude 48.53205 --tilt 32 --azimuth 190

پیش‌نیازها: numpy و requests. اجرای موفق به اینترنت و در دسترس بودن APIهای Open-Meteo و PVGIS نیاز دارد.

به‌طور پیش‌فرض، خروجی‌ها در validations/results/latest/ نوشته می‌شوند. هر اجرای موفق علاوه بر گزارش و CSVها، فایل `dashboard.html` را به‌صورت خودکار تولید می‌کند. فایل را در مرورگر باز کنید؛ برای بارگذاری کتابخانهٔ نمودار Plotly به اینترنت نیاز است. برای آرشیو اجرای جداگانه از --output-dir validations/results/نام-اجرا استفاده کنید تا نتایج قبلی بازنویسی نشوند.

## داشبورد نمودارها\n\nبرای ساخت داشبورد از یک خروجی موجود، بدون اجرای مجدد APIها:\n\n    python validations/build_dashboard.py --input-dir validations/results/latest\n\nداشبورد از داده‌های همان اجرای اعتبارسنجی استفاده می‌کند. نمودار پراکندگی برای خوانایی حداکثر حدود ۱۸۰۰ نقطه را نمایش می‌دهد؛ نمودار زمانی و توزیع باقیمانده از همهٔ رکوردهای ساعتی موجود استفاده می‌کنند.\n\n## تفسیر وضعیت اعتبارسنجی

- مقایسهٔ تابش، اعتبار مدل تابش روی صفحه (POA) است، نه اعتبارسنجی توان الکتریکی.
- مقایسهٔ تولید فقط زمانی منصفانه است که دورهٔ اقلیمی، ظرفیت، جهت، شیب، نوع نصب، تعریف تلفات و مدل توان همسان یا تفاوت‌های آن‌ها مستند شده باشد.
- داده‌های بازتحلیل/ماهواره‌ای مرجع اندازه‌گیری میدانی نیستند. بدون پیرانومتر کالیبره و دادهٔ توان واقعی سایت، نمی‌توان ادعای اعتبارسنجی میدانی یا تضمین تولید کرد.
- خروجی اسکریپت، داده‌ها و پارامترهای درخواست را مستند می‌کند؛ اجرای آنلاین ممکن است با تغییر پایگاه داده یا نسخهٔ API تغییر کند.

این مجموعه در شاخهٔ feature/pv-validation-suite ساخته شده است و تغییری روی main اعمال نمی‌کند.


## نمودارهای داخل نرم‌افزار دسکتاپ

در پنجرهٔ «تحلیل سایت خورشیدی و زاویه بهینه پنل»، پس از پایان تحلیل، دکمهٔ «نمایش نمودارهای اعتبارسنجی» نمودارهای بومی PySide6/Matplotlib را باز می‌کند. این پنجره شامل مقایسهٔ تابش ماهانه با PVGIS، Bias ماهانه، سری زمانی ساعتی، پراکندگی و باقیمانده‌ها، حساسیت جابه‌جایی زمانی و حساسیت تولید نسبت به شیب پنل است. برای نمودارهای اصلی از داده‌های همان اجرای تحلیل استفاده می‌شود؛ داده‌های ساعتی برای ساخت نمودارها در حافظه نگه داشته می‌شوند.

نمودارها مستقل از اتصال اینترنت قابل مشاهده‌اند، پس از آنکه اجرای تحلیل داده‌ها را دریافت کرده باشد. دریافت داده‌ها همچنان به دسترسی شبکه به APIهای مرجع نیاز دارد.
